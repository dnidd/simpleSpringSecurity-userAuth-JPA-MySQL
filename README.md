## Spring security
Multiple user account creation and login.


## Database connection
MySQL, JPA, hibernate.<br>
'user' table created where user id, username and encrypted/hashed
password is stored.

<span style="color:white">––––––––––––––––––––––––––––––––––––––––––––––––––––––––––––––</span>


Hit the following to create/register a user.
http://localhost:8080/api/user/register

Login using JSON:
```
{
    "username": "*****",
    "password": "*****"
    "email": "*****"
}
```

Hit the following to test if the user is logged-in.
http://localhost:8080/api/greet
